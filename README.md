PROJECT DESCRIPTION

For my project, I will be looking at blue carbon sequestration across the Chesapeake Bay salinity gradient. To be able to achieve this I will be using sediment cores collected from six different sites along the Chesapeake Bay including the Susquehanna Flats, the Severn River, Crisfield, Gwynn Island, Goodwin Island, and South Bay. These sediment cores were collected in the Summer of 2025 and 2026. In these cores I will be doing pyrite analysis, grain size analysis, 210Pb dating for sediment accumulation rates, and LOI (loss on ignition). Depending on the salinity of the water and the redox conditions, we expect pyrite burial to be affected by the different salinities with higher carbon storage in more saline environments. 
For this project I will be using my own data. 
The final goal of this project is to be able to couple the geochemical analysis with above-ground carbon content derived from satellite imagery to then be able to estimate carbon burial rates. 


To work this notebook, you will need to download two files, Raw_data2 and LOI_data. 
Variables include core location, core type, core sample depth, grain size (um), pyrite (mg S/g dry weight), and LOI (loss on ignition).  

Measuring pyrite and sediment grain size helps us understand the processes that influence long-term carbon sequestration in SAV sediments. Pyrite (FeS₂) formation is associated with microbial sulfate reduction, which contributes to alkalinity production and can support inorganic carbon storage. Grain size influences sediment permeability, organic matter retention, and the availability of reactive iron needed for pyrite formation. Together, these measurements help determine how sediment characteristics and salinity influence carbon burial and long-term carbon storage across the Chesapeake Bay salinity gradient.
