PROJECT DESCRIPTION
For my project, I will be looking at blue carbon sequestration across the Chesapeake Bay salinity gradient. To be able to achieve this I will be using sediment cores collected from five different sites along the Chesapeake Bay including the Susquehanna Flats, the Severn River, Crisfield, Gwynn Island, Goodwin Island, and South Bay. These sediment cores were collected in the summer of 2025 and 2026. In these cores I will be doing pyrite analysis, grain size analysis, and 210Pb dating to be able to try to achieve carbon sequestration rates. Depending on the salinity of the water and the redox conditions, we expect pyrite burial to be affected by the different salinities with higher carbon storage in more saline environments. 
For this project I will be using my own data since I just finished majority of my data collection this past summer. 
The final goal of this project is to be able to couple the geochemical analysis with above- ground carbon content derived from satellite imagery to then be able to better understand our global carbon cycling.
